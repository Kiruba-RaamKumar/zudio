#  Zudio Sales Performance Dashboard (2024)

 Project Overview

This project focuses on analyzing Zudio's sales performance for 2024 through an interactive Power BI dashboard. It provides insights into sales, profit, store performance, clothing categories, and geographical distribution to help understand overall business performance.

 Key Performance Indicators (KPIs)

- Total Sales: 31M
- Total Profit: 12M
- Total Stores: 3,897
- Profit Percentage: 40%
- Average Selling Price: 1,745

 Dashboard Features

- Monthly Sales Trends (2024)
- Sales by Category
- Sales by State
- Profit by City
- Quantity by Clothing Type
- Sales by Store Type (Owned and Rented)
- Top 10 Sales Performance

 Interactive Filters

- Month
- State

 Tools & Technologies

- Power BI
- SQL
- Data Cleaning
- Data Analysis
- Data Visualization

 Project Objectives

- Analyze monthly sales and profit trends.
- Identify high-performing cities and states.
- Compare sales across clothing categories.
- Analyze store performance.
- Understand product demand and quantity distribution.
- Generate actionable business insights.

 Key Learnings

Developed practical skills in SQL-based data analysis, data cleaning, KPI tracking, geographical visualization, and interactive Power BI dashboard development.
